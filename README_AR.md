# تطبيق مراقبة إشعارات PalPay — تعليمات من الهاتف

هذه حزمة **المصدر البرمجي** وليست APK. تحتوي على إعداد GitHub Actions لبناء APK تلقائياً.

## أسهل رفع من الهاتف
1. أنشئ مستودع GitHub **خاص Private** باسم PalPayNotificationBridge، وحدد إنشاء README إن أردت.
2. افتح المستودع عبر Chrome وفعل **عرض سطح المكتب** إذا لزم.
3. GitHub في المتصفح لا يفك ZIP عند رفعه. لذلك تحتاج رفع الملفات **ومجلداتها مع الحفاظ على المسارات** باستخدام أداة Git على الهاتف تدعم استيراد مجلد مشروع، أو كمبيوتر. لا ترفع ZIP كملف واحد وتتوقع البناء.
4. بعد ظهور الملفات في المستودع، تأكد أن `.github/workflows/build-apk.yml` و`app/` و`settings.gradle.kts` موجودة في جذر المستودع.
5. افتح تبويب Actions، واسم العملية Build Android APK، ثم Run workflow (أو انتظر التشغيل عند الدفع إلى main).
6. بعد نجاح التشغيل، افتح نتيجة البناء ونزّل Artifact المسمى PalPayBridge-debug-apk. فك ضغط ملف Artifact لتحصل على `app-debug.apk`، وثبته على هاتفك.
7. افتح التطبيق، أدخل Package ID الصحيح لتطبيق PalPay ومفتاح PALPAY_INGEST_TOKEN من إعداداتك السرية (لا تضعه في GitHub)، ثم فعّل صلاحية الوصول للإشعارات.

## قيود وأمان
- لم يُبنَ هذا المشروع أو يُختبر على هاتف فعلي هنا. نجاح البناء غير مضمون حتى يكتمل GitHub Actions.
- يرسل فقط إشعارات التحويل الوارد التي يستطيع تفسيرها؛ النصوص الغامضة تُتجاهل.
- لا يعتمد سداد الأسر؛ يسجل إشعارات بانتظار المطابقة في الخادم.
- مفتاح الربط محفوظ حالياً في تفضيلات التطبيق على الهاتف؛ هذه نسخة تجريبية، ويُفضّل تطوير تخزين مشفر ومصادقة جهاز قبل التشغيل المالي الفعلي.
- خدمات Android قد تتوقف بفعل قيود البطارية، ولا تضمن التقاط كل إشعار.
- لا تضع مفاتيح أو بيانات شخصية في المستودع.
